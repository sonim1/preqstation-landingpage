Public npm package와 사용자-facing command는 `@sonim1/preqstation`, `preqstation`입니다. OpenClaw는 PREQ dispatcher plugin을 로드하고, plugin은 프로젝트를 찾고 worktree를 만들고 `.preqstation-prompt.txt`를 쓴 다음 Claude Code, Codex, Gemini CLI를 detached process로 실행합니다.

일부 plugin/config identifier에는 호환성을 위해 아직 `preqstation-dispatcher` 또는 `preqstation-openclaw`가 남아 있을 수 있습니다. 명령이 명시적으로 요구하지 않는 한 legacy technical identifier로만 보세요.

이 페이지는 **OpenClaw dispatcher** 경로를 쓸 때 봅니다.

OpenClaw는 아래 경우에 적합합니다.

- OpenClaw 채널을 통한 Telegram-triggered dispatch
- 복사한 OpenClaw dispatch 명령 실행
- OpenClaw-native `/preqsetup` project mapping
- OpenClaw host에서 detached, worktree-first 실행

## 설치 전에 필요한 것

아래가 필요합니다.

- dispatcher host에 OpenClaw 설치
- PreqStation이 dispatch할 프로젝트의 로컬 checkout
- OpenClaw host에서 실행 가능한 worker CLI: `claude`, `codex`, `gemini` 중 하나 이상
- CLI installer 또는 [워커 설치](/guide/ko/skill/installation)에 따른 PREQ worker 설정
- 웹 앱에서 Telegram으로 dispatch message를 보낼 경우 Telegram 설정

에이전트가 자기 터미널에서 직접 PREQ task를 처리하면 충분하다면 worker 설정까지만 하면 됩니다. OpenClaw는 웹 앱이나 OpenClaw chat에서 queued dispatch를 보낼 때 쓰는 경로입니다.

## PREQ CLI로 설치

OpenClaw가 실행되는 머신에서 installer를 실행합니다.

```bash
npx -y @sonim1/preqstation@latest install
```

`preqstation`을 이미 전역 설치했다면 OpenClaw integration만 설치하거나 갱신할 수 있습니다.

```bash
preqstation install openclaw
openclaw gateway restart
```

Installer가 OpenClaw plugin install flow를 대신 실행합니다. npm package와 binary는 `@sonim1/preqstation`, `preqstation`이고, OpenClaw plugin id는 여전히 `preqstation-dispatcher`일 수 있습니다.

## 수동 Fallback 또는 로컬 개발

CLI installer가 plugin 설치 명령을 실행하지 못하거나 plugin을 로컬 개발 중일 때만 사용하세요.

```bash
openclaw plugins install @sonim1/preqstation --dangerously-force-unsafe-install
openclaw gateway restart
```

로컬 개발 중인 checkout을 연결하려면:

```bash
openclaw plugins install --link --dangerously-force-unsafe-install /path/to/preqstation
openclaw gateway restart
```

이 plugin은 git worktree를 만들고 detached coding CLI를 실행하기 위해 로컬 process 실행을 사용합니다. 그래서 현재 OpenClaw install에는 `--dangerously-force-unsafe-install`이 필요합니다.

## 설치 확인

```bash
openclaw plugins inspect preqstation-dispatcher
openclaw status --all
preqstation status openclaw
```

## 프로젝트 경로 매핑

설치 후 OpenClaw host에서 PREQ project key를 로컬 checkout에 매핑합니다.

<Tabs>
<TabItem label="Auto">
```bash
preqstation setup auto PROJ=https://github.com/example/project
```

OpenClaw chat command로도 plugin-native setup command를 실행할 수 있습니다.

```text
/preqsetup auto PROJ=https://github.com/example/project
```

`/preqsetup auto`는 `PREQSTATION_REPO_ROOTS`가 있으면 그 아래를, 없으면 `~/projects` 아래의 git repo를 스캔합니다. 로컬 `origin` URL과 전달한 repo URL을 비교해서 맞는 checkout을 OpenClaw plugin config에 저장합니다.
</TabItem>
<TabItem label="Manual">
```bash
preqstation setup set PROJ /absolute/path/to/project
preqstation setup status
```

OpenClaw-native equivalent:

```text
/preqsetup set PROJ /absolute/path/to/project
/preqsetup status
```
</TabItem>
<TabItem label="Shared Store">
```text
/preqsetup import
```

다른 dispatcher host가 이미 `~/.preqstation-dispatch/projects.json`을 채워두었을 때 사용합니다.
</TabItem>
</Tabs>

유용한 CLI setup 명령:

```bash
preqstation setup auto
preqstation setup set <PROJECT_KEY> <ABSOLUTE_PATH>
preqstation setup status
preqstation setup unset PROJ
```

유용한 OpenClaw-native setup 명령:

```text
/preqsetup
/preqsetup auto
/preqsetup import
/preqsetup set <PROJECT_KEY> <ABSOLUTE_PATH>
/preqsetup status
/preqsetup unset PROJ
```

해석 순서:

1. 메시지에 직접 포함된 절대 경로
2. 저장된 OpenClaw plugin mapping
3. 공유 `~/.preqstation-dispatch/projects.json`
4. legacy `MEMORY.md` fallback

## Worktree Root

PREQ CLI는 task worktree에 `PREQSTATION_WORKTREE_ROOT`를 사용합니다. OpenClaw-specific legacy install은 아직 `OPENCLAW_WORKTREE_ROOT`를 읽을 수 있습니다.

```bash
export PREQSTATION_WORKTREE_ROOT="$HOME/.preqstation-dispatch/worktrees"
```

기본값: `~/.preqstation-dispatch/worktrees`

각 task는 전용 worktree에서 실행됩니다.

```text
<PREQSTATION_WORKTREE_ROOT>/<project_key>/<branch_slug>/
```

Detached runtime artifact는 그 worktree 안에 기록됩니다.

```text
.preqstation-dispatch/<engine>.pid
.preqstation-dispatch/<engine>.log
```

## Engine 키

OpenClaw는 PREQ engine key를 로컬 CLI binary로 매핑합니다.

| Engine key | Local binary |
|---|---|
| `claude-code` | `claude` |
| `codex` | `codex` |
| `gemini-cli` | `gemini` |

기본 engine key: `claude-code`

선택한 CLI가 OpenClaw gateway process에서 접근 가능한 안정적인 실행 경로에 설치되어 있는지 확인하세요.

## Dispatch 명령

OpenClaw adapter는 일반 chat run 전에 명시적인 PREQ dispatch message를 가로채 처리합니다.

```text
!/skill preqstation-dispatch implement PROJ-284 using codex branch_name="task/proj-284-example"
/skill preqstation-dispatch review PROJ-284 using claude-code
/skill preqstation-dispatch ask PROJ-285 using gemini-cli ask_hint="Acceptance criteria"
```

웹 앱의 Telegram/OpenClaw send도 같은 OpenClaw command shape을 사용합니다.
