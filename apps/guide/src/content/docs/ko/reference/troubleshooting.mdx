한국어 상세 번역은 아직 준비 중입니다. 현재 구현 상태와 맞는 최신 문제 해결 절차는 영어 문서를 기준으로 유지됩니다.

## 먼저 doctor/status 실행

수동으로 runtime이나 MCP 설정을 뜯어보기 전에 PREQ CLI 진단부터 실행하세요.

```bash
preqstation doctor
preqstation status
preqstation doctor --json
preqstation status --json
```

일반 출력은 사람이 직접 확인할 때 쓰고, JSON 출력은 report, script, monitoring에 구조화된 진단을 넘길 때 사용합니다.

## 주요 확인 순서

1. Server URL과 remote `/mcp` endpoint가 올바른지 확인합니다.
2. OAuth login flow가 끝났는지 확인합니다.
3. Claude Code, Codex CLI, Gemini CLI의 MCP registration을 확인합니다.
4. `preqstation setup status`, `preqstation setup auto`, `preqstation setup set`으로 local project mapping을 확인합니다.
5. `claude`, `codex`, `gemini` 실행 파일이 host process `PATH`에서 보이는지 확인합니다.
6. `fnm` 같은 session-scoped Node 설정에만 의존했다면 host process 환경을 고치고 OpenClaw/Hermes를 재시작합니다.
7. Hermes profile에 terminal/tool execution이 켜져 있는지 확인합니다.
8. `PREQSTATION_TOKEN`과 `/api-keys`는 shell-helper mode 또는 legacy local bridge compatibility path에서만 확인합니다.

전체 단계와 예시는 [영어 Troubleshooting](/guide/reference/troubleshooting)을 참고하세요.
