PreqStation은 Claude, Codex, Gemini를 실제 프로젝트에 연결하기 위한 실행 시스템입니다.

## 추천 첫 단계

처음 PreqStation을 설정한다면 [빠른 시작](/guide/ko/getting-started/quick-start)부터 시작하세요. 가장 짧은 경로는 PREQ CLI installer에서 시작합니다.

```bash
npx -y @sonim1/preqstation@latest install
```

Installer는 기본 CLI 경로, worker runtime support, 원격 MCP 등록, 선택적 dispatcher 설정을 함께 다룹니다. 전체 operator-host command guide는 [PREQ CLI](/guide/ko/getting-started/preq-cli)를 참고하세요. 웹 앱을 self-hosting하거나 migration을 검증한다면 [웹 앱 설정](/guide/ko/web-app/setup)으로 이어가면 됩니다.

## 설정 경로 선택

### 1. CLI 기본 설정

- [빠른 시작](/guide/ko/getting-started/quick-start) — `npx -y @sonim1/preqstation@latest install`, `status`, MCP 등록, project mapping까지 가장 빠르게 진행
- [PREQ CLI](/guide/ko/getting-started/preq-cli) — operator-host install, lifecycle check, integration install, project mapping
- [환경 변수](/guide/ko/reference/environment-variables) — dispatcher home, worker home, project mapping, token 호환성 변수 확인

### 2. Worker-only 설정

- [워커 설치](/guide/ko/skill/installation) — 전체 CLI installer 경로를 쓰지 않을 때 Claude, Codex, Gemini worker를 수동 연결

### 3. 디스패처 설정

웹 앱에서 queued dispatch가 필요할 때만 dispatcher를 추가하세요.

- [OpenClaw 설치](/guide/ko/openclaw/setup) — 웹 앱에서 Telegram/OpenClaw 전달 사용
- [Telegram 연동](/guide/ko/web-app/telegram) — Hermes Telegram 전달과 QA 큐잉

### 4. 웹 앱과 레거시 호환성

- [웹 앱 설정](/guide/ko/web-app/setup) — 환경 변수, migration, 첫 로그인까지 전체 웹 앱 설정 확인
- [API Keys](/guide/ko/web-app/api-keys) — shell-helper mode와 legacy local bridge용 token 설정

## PreqStation 구성 이해하기

- **PreqStation 웹 앱** — 칸반 UI, REST API, dispatch 액션 UI, Telegram relay, 실행 오버레이를 제공하는 중심 웹 앱
- **preqstation-skill** — Claude Code, Codex, Gemini CLI가 태스크를 읽고 상태를 갱신할 때 쓰는 MCP/worker 패키지
- **PREQ CLI** — 사용자-facing npm package와 command: `@sonim1/preqstation`, `preqstation`
- **preqstation-dispatcher** — OpenClaw와 Hermes 실행 뒤에 있는 역사적/internal dispatcher surface. 일부 plugin/config identifier는 호환성을 위해 아직 `preqstation-dispatcher` 또는 `preqstation-openclaw`를 언급할 수 있습니다.

task의 **engine**이 실제로 `claude-code`, `codex`, `gemini-cli` 중 어떤 CLI를 띄울지 결정하고, queued dispatcher 경로는 그와 별도로 동작합니다.

처음 설치라면 PREQ CLI installer부터 실행하세요. worker를 이미 직접 쓰고 있다면 worker-only 설정을 보고, 큐 기반 전달이 필요할 때만 OpenClaw 또는 Hermes를 추가하면 됩니다. 예전 token setup은 API key 호환성 문서를 참고하세요.

이 시스템은 “이슈를 모아두는 백로그”보다, 이미 범위가 정해진 작업을 실제로 실행시키는 데 맞습니다.

태스크를 만드세요. 에이전트가 계획하고 구현하고 검증합니다. 마지막 판단과 승인만 당신이 합니다.
