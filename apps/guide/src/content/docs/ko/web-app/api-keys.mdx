---
title: 레거시 API Keys
description: Shell-helper compatibility와 direct REST automation을 위한 legacy Bearer token입니다.
---

PREQ CLI가 새 operator host의 기본 설치 경로입니다. Remote `/mcp`와 browser OAuth는 Claude Code, Codex CLI, Gemini CLI가 PREQ MCP tool을 직접 호출해야 할 때 쓰는 optional direct-client compatibility입니다. `/api-keys`와 `PREQSTATION_TOKEN`은 shell-helper mode, direct REST automation, 예전 local bridge flow가 아직 필요할 때만 사용하는 compatibility path입니다.

새 설치라면 특정 client가 PREQ CLI 또는 optional remote MCP OAuth를 사용할 수 없을 때만 token을 만드세요.

| 경로 | 언제 쓰나 | 관리하는 secret |
|---|---|---|
| PREQ CLI | operator host가 인증, project mapping, dispatch/direct run을 실행할 때 | `~/.preqstation` 아래 CLI auth cache |
| Remote `/mcp` + OAuth | direct-client Claude Code, Codex, Gemini CLI가 hosted MCP tool을 직접 호출해야 할 때 | browser OAuth session |
| Legacy API key | Shell helper, direct REST script, 예전 local bridge가 bearer auth를 요구할 때 | `PREQSTATION_TOKEN` |

## 언제 token을 쓰나

- Shell-helper mode를 유지 중일 때
- Direct REST automation이 bearer token을 요구할 때
- 예전 local stdio bridge를 아직 사용해야 할 때

새 설치라면 먼저 [빠른 시작](/guide/ko/getting-started/quick-start/)과 [PREQ CLI](/guide/ko/getting-started/preq-cli/)를 사용하세요.

## Compatibility 설정

```bash
export PREQSTATION_API_URL=https://your-domain.com
export PREQSTATION_TOKEN=preq_xxxxxxxxxxxxx
```

Token은 한 번만 표시되므로 공유하거나 version control에 저장하지 마세요. 노출되면 legacy token management flow에서 revoke한 뒤 새 token을 발급하세요.
