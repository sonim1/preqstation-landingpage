PreqStation MCP server는 read-only discovery tool과 direct-client compatibility용 mutation tool을 제공합니다. Detached dispatch worker는 보통 `.preqstation-instructions.txt`의 PREQ CLI command를 사용합니다. Client가 MCP tool을 직접 호출해야 할 때 이 페이지를 참고하세요.

## Side effect 요약

| Category | Tools | Side effect |
|---|---|---|
| Read-only | `preq_list_projects`, `preq_list_tasks`, `preq_get_task`, `preq_get_project_settings` | workflow 변경 없음 |
| Planning | `preq_plan_task` | `inbox` -> `todo` |
| Execution | `preq_start_task`, `preq_complete_task`, `preq_block_task` | run state 또는 workflow state 변경 |
| Review | `preq_review_task`, `preq_update_qa_run` | verification 기록, `ready` -> `done` 가능 |
| Manual override | `preq_update_task_status`, `preq_update_task_note`, `preq_delete_task` | 직접 mutation |

## Engine 값

- `claude-code`
- `codex`
- `gemini-cli`

Mutation tool은 explicit `engine`, 기존 task engine, MCP client auto-detection, `PREQSTATION_ENGINE`, `codex` fallback 순서로 engine을 결정합니다.

전체 parameter와 request/response 예시는 [영어 MCP Tools reference](/guide/skill/mcp-tools/)를 참고하세요.
