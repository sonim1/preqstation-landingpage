PreqStation should remain the lifecycle source of truth. GBrain is a private durable memory and handoff layer that stores context agents may need later without putting that memory into public or source-controlled repositories.

<Aside type="caution">
The paths and project keys below are examples. Replace `~/projects`, `~/brain`, `~/gbrain`, repository roots, brain folders, and PREQ project keys with values that match your own machine and team. Do not copy the example mapping blindly.
</Aside>

## What This Integration Does

Use this pattern when you want agents to keep useful task memory across runs while keeping the actual source repository clean.

- PreqStation owns task status, acceptance criteria, work logs, and lifecycle transitions.
- GBrain stores private handoff notes, durable summaries, and operator context outside the source repo.
- The sync process reads from PreqStation and writes into a private brain folder.
- Source repos stay free of generated memory files, task dumps, and private implementation notes.

The sync should be read-only from PreqStation and write-only into your private GBrain workspace. It must not change task status.

## Customize These Paths First

Decide the real paths before you run an agent setup prompt or cron job.

| Example | Replace with |
|---|---|
| `~/projects/preqstation-lp` | Your repo root for the project |
| `~/brain/preqstation` | Your private memory folder for this project |
| `~/gbrain` | Your local GBrain checkout or runtime folder |
| `PQSL` | Your PreqStation project key |

Keep the private memory folder outside every source repo. If your repo is in `~/projects/my-app`, choose a sibling or separate private location such as `~/brain/my-app`.

## Recommended Folder Layout

```text
~
├── projects/
│   └── preqstation-lp/        # source repo
├── brain/
│   └── preqstation/           # private memory, not committed
│       ├── tasks/
│       ├── handoffs/
│       ├── decisions.md
│       └── project-map.md
└── gbrain/                    # GBrain runtime or checkout
```

Add a local ignore rule if there is any chance a brain folder may be created near a repo:

```text
.brain/
brain/
gbrain/
*.handoff.md
```

Prefer keeping the folder outside the repo rather than relying only on `.gitignore`.

## Why This Is Safe for Public Repos

The source repo should only contain product code, docs, tests, and project-owned assets. Private run memory can contain implementation notes, operator preferences, temporary paths, unreleased details, or security-sensitive context. Keeping that memory outside the repo prevents accidental commits and makes public or open-source repositories safer to work in.

The boundary is simple:

- PreqStation: canonical task state and acceptance criteria
- Source repo: code and documentation intended to ship
- GBrain: private memory and handoff context

## What Gets Synced

Sync concise material that improves future execution:

- Task key, title, status, labels, and acceptance criteria
- Current note or plan, summarized for future agents
- Latest result summary and test commands
- Durable decisions, blockers, and handoff notes
- Links to PreqStation tasks rather than full replicated task dumps

Do not sync noisy or sensitive material:

- Full task dumps on every cron run
- Secrets, tokens, API keys, or private customer data
- Generated logs that are not needed for handoff
- Large artifacts already stored elsewhere
- Anything that belongs in the source repo as reviewed documentation

## Recommended GBrain Project Files

Start with a small set of stable files:

```text
~/brain/preqstation/
├── project-map.md
├── decisions.md
├── tasks/
│   └── PQSL-18.md
└── handoffs/
    └── latest.md
```

`project-map.md` should describe your local repo path, PREQ project key, private brain path, and any naming conventions. `decisions.md` should contain stable decisions only. Task files should be concise and replaceable.

## One-shot Agent Setup Prompt

Use a prompt like this once per project after changing the paths to your own values:

```text
Set up private GBrain memory for this PreqStation project.

Project key: PQSL
Source repo: ~/projects/preqstation-lp
Private brain folder: ~/brain/preqstation
GBrain runtime: ~/gbrain

Rules:
- PreqStation is the lifecycle source of truth.
- Read task metadata and latest result from PreqStation only.
- Write concise handoff memory only under ~/brain/preqstation.
- Do not create brain notes inside the source repo.
- Do not call lifecycle mutation tools during memory sync.
- Do not commit or push private memory.

Create the folder layout, write project-map.md, and create a short latest.md handoff note.
```

## Daily Sync Cron Prompt

Schedule a daily sync only after the manual run produces the right files.

```text
Daily PreqStation to GBrain sync for project PQSL.

Read current PreqStation tasks and latest task results.
Update concise private memory under ~/brain/preqstation.

Strict rules:
- This is read-only from PreqStation.
- This is write-only into the private brain folder.
- Do not call preq_update_task_status.
- Do not call preq_complete_task.
- Do not call preq_review_task.
- Do not call preq_block_task.
- Do not write into source repositories.
- Do not overwrite hand-authored notes unless the file says it is generated.

Output a short sync summary with changed files.
```

Example cron wrapper:

```bash
0 8 * * * cd ~/gbrain && gbrain run --prompt-file ~/brain/preqstation/daily-sync.prompt.txt >> ~/brain/preqstation/sync.log 2>&1
```

Adjust the command to match your actual GBrain CLI or automation runtime.

## Optional Project Mapping

If you manage several PreqStation projects, keep a private mapping file outside the repos:

```md
# PreqStation Project Mapping

| Project | Repo | Brain folder |
|---|---|---|
| PQSL | ~/projects/preqstation-lp | ~/brain/preqstation |
| APP | ~/projects/my-app | ~/brain/my-app |
```

This file is private operator configuration, not project documentation. Do not commit it unless your team intentionally maintains a sanitized version.

## Manual Verification

Before enabling any scheduled sync, verify the boundaries manually:

1. Run the setup prompt once.
2. Confirm files were created only under the private brain folder.
3. Run `git status` in the source repo and confirm no brain files appeared.
4. Open the generated task note and confirm it is concise.
5. Confirm no PreqStation task status changed.

For this guide app, verify the docs route with:

```bash
pnpm --filter @preqstation/guide build
```

Then check `/guide/advanced/gbrain/` and the localized route if enabled.

## Troubleshooting

**Brain files appeared in the source repo**

Move them to the private brain folder, add local ignore rules, and check `git status` before committing. Do not commit private memory.

**The sync changed PreqStation task status**

Stop the automation. Memory sync must never call lifecycle mutation tools. Restore the task state from the PreqStation board before re-enabling the job.

**The brain folder is full of repeated dumps**

Change the prompt to summarize durable decisions and handoff context. Keep links back to PreqStation for canonical details.

**A generated file overwrote hand-written notes**

Separate generated files from hand-authored files. Use filenames such as `generated/latest.md` for replaceable output and keep `decisions.md` manual.

## What Agents Must Avoid

- Creating repo-local brain notes such as `docs/brain.md` or `.brain/tasks/*.md`
- Dumping every PreqStation field into GBrain on every run
- Calling PREQ lifecycle mutations during sync
- Committing or pushing private memory
- Blindly overwriting hand-authored notes
- Treating GBrain as the source of truth for task status

When in doubt, keep PreqStation canonical, keep GBrain private, and keep source repos clean.
